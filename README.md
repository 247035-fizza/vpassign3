# Certo Assignment

A static front-end webpage built as part of the Certo assignment, replicating the layout and design of the Certo mobile security product landing page.

## Project Structure

```
├── index.html          # Main HTML file
├── assets/
│   ├── css/
│   │   └── style.css   # Custom styles
│   └── images/
│       └── header.svg  # Logo and icon assets
└── README.md
```

## Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap 5.3**

## Sections

- **Navbar** — Logo, navigation links, and Sign In button
- **Hero** — Headline, subtext, and hero image
- **Features** — Three-step process cards
- **Reviews** — Customer testimonials with star ratings
- **Footer** — Branding and copyright

## Getting Started

No build tools required. Simply open `index.html` in a browser.

```bash
# Clone the repo
git clone https://github.com/fizza-247035/vpassign3.git

# Open in browser
open index.html
```
